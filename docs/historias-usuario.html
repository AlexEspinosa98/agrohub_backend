Como integrador de un frontend, quiero que cualquier error de validación (en cualquier módulo) devuelva la misma forma, con campo, mensaje, tipo de error y valor recibido, para armar un manejo de errores genérico.

HU-T02

Bloqueo por rol antes de asignación

Como sistema, quiero que ningún usuario recién registrado use un endpoint protegido hasta que un superadmin le asigne un rol explícitamente, para que el acceso sea siempre una decisión humana, no un descuido de configuración.

Respuesta 403 — usuario sin rol
{ "detail": "Tu cuenta aún no tiene un rol asignado. Contacta a un superadmin." }
